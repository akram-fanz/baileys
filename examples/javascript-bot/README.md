# WhatsApp Bot JS

Simple WhatsApp bot built with `@vibersmoon/baileys` and `@whiskeysockets/baileys`.

## Install

```bash
npm install
```

## Run

```bash
npm start
```

Scan the QR code with your WhatsApp mobile app to authenticate.

## Commands

| Command | Response |
|---------|----------|
| `ping` | `pong 🏓` |
| `!echo <text>` | Echoes your text |
| `!info` | Bot version info |
| `!help` | List commands |

## Project structure

- `index.js` — Bot entry point and command handlers
- `package.json` — Dependencies
